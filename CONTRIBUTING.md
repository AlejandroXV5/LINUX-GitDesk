# Cómo proponer mejoras

GitDesk se puede instalar y usar libremente, pero el código solo lo cambia su autor (ver [LICENSE](LICENSE)). Si tienes una mejora, una corrección o un cambio de configuración, propónmelo y yo decido si lo incorporo.

## Opción 1 — Abrir un Issue (recomendado)

En la pestaña **Issues** del repositorio, pulsa **New issue** y cuenta:

- **Qué quieres:** la mejora, el error o la configuración que cambiarías.
- **Por qué:** qué problema resuelve o qué te gustaría poder hacer.
- **Si es un error:** los pasos para reproducirlo, tu distribución de Linux y el texto del panel **Output** de GitDesk.

## Opción 2 — Enviar un Pull Request

Si ya tienes el cambio hecho, puedes hacer un fork, aplicarlo ahí y abrir un Pull Request hacia `main`. La licencia permite modificar tu fork **solo para preparar ese Pull Request**: no puedes usar ni compartir la versión modificada por tu cuenta. Al enviarlo, me autorizas a usar tu cambio en GitDesk.

Nadie más que el autor puede subir cambios a este repositorio: los Pull Requests solo entran si los acepto.

## Preferencias de la aplicación

Las opciones del menú **Opciones** de GitDesk (idioma, tema, identidad de git, fetch automático, etc.) son tuyas: cámbialas cuando quieras, no hace falta proponerlas.
