The one strip in GitDesk that breaks the surface-200 plane on purpose: a solid `brand-solid` fill with `ink-inverse` text, so "which repository, which branch, is anything unsynced" is answerable without looking away from whatever else is on screen — the same reason a terminal multiplexer or a code editor colors its status line. Left-aligned: current branch, ahead count, behind count, each a clickable chip that opens the matching action (branch switcher, push, pull). Right-aligned and non-interactive (`muted`): file encoding, line-ending style, the working-tree change count — facts, not actions. The `spacer` keeps that split fixed regardless of how many chips either side holds.
