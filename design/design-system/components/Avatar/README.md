A 20px circle with the author's initials in `ink-inverse`, filled from `identity-1`…`identity-5` cycled by author (hashed from their name, not by commit order) so the same person keeps the same color across a session. These five are the one color family that stays identical between the dark and light theme — a teammate's color is an identity, not a mode-dependent decoration, and fixing it means it was chosen to hold ≥4.5:1 under white initials in both themes rather than borrowed from the graph-lane palette, which is tuned for lines on a surface, not fills under text.

The merge-commit avatar (three dots joined by a curve) replaces an author's initials only on a genuine merge with more than one parent shown collapsed; it uses `surface-hover` fill and `ink-secondary`, deliberately quieter than any real author's avatar.
