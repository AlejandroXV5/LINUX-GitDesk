The sidebar: a filter box, then one scrolling tree under three collapsible sections — Branches / Tags, Pull Requests, Submodules — each a `section-head` in `label` type with its own chevron, independent of the others.

Depth is spacing, not a rule or a connecting line: each level indents by 16px (`depth0`→`depth1`→`depth2`) so a deeply nested `remotes/origin/release/hotfix` reads as a stack without the tree turning into a grid of dashes. A folder row always carries its own small chevron immediately before its icon, distinct from the section's chevron, so "this group is collapsed" and "this whole section is collapsed" never look identical.

Icon color carries meaning before the label does: `brand` marks whatever HEAD points at (the worktree root's diamond, the current branch's fork glyph) so it's findable in a long list without reading every line; local branches otherwise use `status-added` (a live, checkable-out ref), remote-tracking branches use `brand` at rest, tags use `status-warning`. A row selected by click gets `accent-selected-bg` with every glyph and label flipped to `ink-inverse` — including the branch and remote icons, which is why those two also had to clear 4.5:1 as `ink-inverse` substitutes, not just as `ink-secondary` originals.

Ahead/behind counts appear only when non-zero, right-aligned, using the same `ahead`/`behind` pill as the toolbar and status bar. The current branch additionally gets a trailing check mark in `brand` (or `ink-inverse` once selected) — two independent signals, color and mark, so "this is HEAD" survives color-blindness and a busy selection state at once. An empty section states the fact plainly (`There are currently no pull requests.`); Submodules keeps a small `+` affordance at all times, since adding one is the only action that section needs.
