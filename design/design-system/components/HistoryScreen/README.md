The same window shell as ChangesScreen, with the main panel swapped for CommitGraph and the sidebar's selection moved to the repository root — this is what `Repository → View History` opens. The shell (title bar, menu bar, toolbar, status bar) never changes shape between the two screens; only `.main`'s content does, which is the whole point of building the shell as its own fixed-height bands in the first place. Compare the two screens side by side to check that a developer never has to relearn where anything lives when they switch from committing to browsing history.
