The repository's full history as one continuously scrolling table — six columns (Branch/Tag, Graph, Message, Author, Date, ID), one row per commit, newest at the top. Above the table, two lines of sync status stay pinned regardless of scroll position: `Incoming (N)` with `Fetch`/`Pull`, `Local History (N Outgoing)` with `Push`/`Sync` — the same two facts the status bar shows as chips, spelled out here because this is the panel where a developer decides whether to act on them.

**Graph column.** Each lane is a fixed 16px column position (`x = 8, 24, 40…`) drawn with `graph-1`…`graph-5` in a fixed rotation — `graph-1` is reserved for whichever lane HEAD is on, so the eye can find "where am I" in a graph with a dozen lanes without reading a single label. A commit dot sits at the row's vertical center on its lane; two lines entering or leaving a dot mean a merge or a branch point and are drawn as one smooth curve between adjacent rows, never a right angle — Git history branches, it doesn't turn corners. The HEAD commit's dot gets an outer `brand` ring on top of its lane fill, the one place a ring, not just a fill, marks state, because "where HEAD is" has to survive on a dot that might otherwise be any color in the rotation.

**Branch/Tag column.** Empty on most rows; a filled `chip` appears only on a commit some ref actually points at. The `head` variant (solid `brand-solid` fill) marks the checked-out branch; a plain outlined chip in `status-warning` marks a tag — same outline treatment as a tag row in the sidebar tree, so the two panels teach one visual grammar for "tag" rather than two.

**Row selection** uses the same `accent-selected-bg` + `ink-inverse` pattern as every other list in GitDesk, including inside the graph SVG itself — a selected row's lane lines and dot are exempted from the inverse-text swap because they're already a fixed, saturated hue chosen to read on both `surface-200` and `accent-selected-bg` without changing.

**Author.** A commit's avatar plus name; a merge with more than one author collapses to the neutral merge glyph from Avatar rather than picking one name arbitrarily. **Date** stays relative (`2 hours ago`, `Yesterday`) up to a week, then falls back to an absolute date — a rule for the eventual build, not visible in this static sample. **ID** is always `code` style, the seven-character short SHA: the one column in this table where exact characters, not a scanned shape, are the point.
