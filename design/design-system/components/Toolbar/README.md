The five actions a developer reaches for without opening a menu — Fetch, Pull, Push, Branch, Stash — as labeled icon buttons, not icon-only: at 44px tall there's room for the word, and a mis-click between Fetch and Pull is expensive enough to earn the extra width. A thin `border-subtle` separator splits sync actions (Fetch/Pull/Push) from repository actions (Branch/Stash); the search field is pinned right with a `spacer` between, so it never drifts as buttons are added. Push carries its outgoing-commit count as the same `count` pill used on the icon-only button elsewhere — one indicator, two contexts.
