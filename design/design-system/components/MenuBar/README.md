A standard desktop menu bar — File, Edit, View, Repository, Branch, Commit, Help — because a Git client has dozens of operations that don't fit a toolbar (rebase interactively, configure remotes, manage submodules) and a menu is where a developer already expects to find the rare ones. `Repository`, `Branch` and `Commit` are GitDesk's own additions beyond a generic app menu, grouping Git's actual verbs the way the sidebar and panels are grouped, so the menu bar teaches the same vocabulary the rest of the window uses. An open menu uses `accent-selected-bg` on its trigger, matching a selected row anywhere else in the app.
